## 🚀 Інструкція з запуску

### 1. Встановлення
```bash
pip install -r requirements.txt
```

### 2. Створення першого адміна
```bash
python create_admin.py
```

### 3. Запуск додатку
```bash
python run.py
```

### 4. Відкрити у браузері
```
http://localhost:5000
```
