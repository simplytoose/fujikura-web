### 4. ✅ `routes_applicators.py` - ОНОВЛЕНО

**Обсяг змін:** 1 розширена функція + 4 нові маршрути

#### 4.1 Розширена функція edit_applicator()
- **Додано полі:** Обробка поля `name`
- **Додано валідація:** Перевірка що `name` не пустое
- **Додано обробка:** Поля `notes` окремо від `name`
- **Оновлено повідомлення:** "Аплікатор успішно оновлено"

#### 4.2 НОВИЙ МАРШРУТ: update_applicator_name() [POST]
- **URL:** `/applicators/<applicator_id>/update-name`
- **Метод:** POST JSON
- **Повна:** admin_required
- **Повертає:** JSON з success флагом

#### 4.3 НОВИЙ МАРШРУТ: get_comments() [GET]
- **URL:** `/applicators/<applicator_id>/comments`
- **Метод:** GET
- **Доступ:** login_required
- **Повертає:** JSON список коментарів

#### 4.4 НОВИЙ МАРШРУТ: add_comment() [POST]
- **URL:** `/applicators/<applicator_id>/comment`
- **Метод:** POST JSON
- **Доступ:** login_required
- **Параметр:** `text` (текст коментаря)
- **Повертає:** JSON з success флагом

#### 4.5 НОВИЙ МАРШРУТ: delete_comment() [DELETE]
- **URL:** `/applicators/<applicator_id>/comment/<comment_id>`
- **Метод:** DELETE
- **Доступ:** login_required (адміністратори)
- **Параметр:** `comment_id` (timestamp ID)
- **Повертає:** JSON з success флагом
