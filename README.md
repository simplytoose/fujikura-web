# Система обліку та відстеження аплікаторів

## Опис

Повнофункціональна веб-система для управління та відстеження аплікаторів на виробництві. Система дозволяє відслідковувати переміщення аплікаторів між різними дільницями, управління машинами, ведення історії та блокування несправних аплікаторів.

## Особливості

- 👥 Ролева система доступу (Адміністратор, Технік, Оператор)
- 📊 Інтерактивний Dashboard зі статистикою
- 🔧 Управління аплікаторами та їхніми статусами
- 🏭 Відстеження на 30 машинах (G01-G30 для нарізки, P01-P05 для кримпування)
- 📜 Повна історія переміщень та блокування
- 🔒 Безпечна аутентифікація з хешуванням паролів
- 📱 Адаптивний дизайн Bootstrap 5
- 🌐 REST API для операцій

## Технології

- **Backend**: Flask 3.0.0, Python 3.12+
- **Database**: SQLite з SQLAlchemy ORM
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **UI Framework**: Bootstrap 5.3
- **Authentication**: Session-based з Flask-Login
- **Web Server**: Flask development server

## Основні сторінки

### Dashboard (`/dashboard`)
- Загальна статистика по аплікаторам
- Стан машин нарізки та кримпування
- Швидкі посилання на основні функції

### Аплікатори (`/applicators`)
- Список всіх аплікаторів з фільтрацією
- Детальна інформація про кожен аплікатор
- Можливість блокування/розблокування
- Переглядання історії переміщень

### Локації
- **Aplicator Room**: Основне сховище (300 комірок)
- **Дільниця обслуговування**: Налаштування аплікаторів
- **Дільниця нарізки**: 30 машин (G01-G30), макс 5 аплік. на машину
- **Дільниця кримпування**: 5 машин (P01-P05), макс 3 аплік. на машину
- **Заблоковані**: Несправні аплікатори
- **Не використовуються**: Виведені з експлуатації

### Машини
- Детальний перегляд кожної машини
- Список аплікаторів на машині
- Стан заповнення та попередження

### Історія
- **Переміщення**: Повна історія переміщень з фільтрацією
- **Блокування**: Історія блокування/розблокування

### Адміністрація
- Управління користувачами
- Створення нових користувачів
- Зміна ролей та статусів

## API Endpoints

### Аутентифікація
- `POST /auth/login` - Вхід
- `GET /auth/logout` - Вихід

### Аплікатори
- `GET /applicators/` - Список аплікаторів
- `GET /applicators/<id>` - Деталі аплікатора
- `POST /applicators/add` - Додати аплікатор
- `POST /applicators/<id>/block` - Заблокувати
- `POST /applicators/<id>/unblock` - Розблокувати
- `POST /applicators/<id>/confirm-service` - Підтвердити обслуговування

### Машини
- `GET /machines/cutting` - Машини нарізки
- `GET /machines/crimping` - Машини кримпування
- `POST /machines/add-to-machine` - Додати на машину
- `POST /machines/remove-from-machine` - Видалити з машини

### Історія
- `GET /history/` - Історія переміщень
- `GET /history/blocking` - Історія блокування

## Статуси аплікаторів

| Статус | Опис | Можливі дії |
|--------|------|-----------|
| AVAILABLE | Доступний для використання | Розміщення на машину, блокування |
| SERVICE | На обслуговуванні | Підтвердження, видалення |
| CUTTING | На нарізці | Видалення, блокування |
| CRIMPING | На кримпуванні | Видалення, блокування |
| BLOCKED | Заблокований | Розблокування (лише технік) |
| INACTIVE | Виведений з експлуатації | Переміщення (лише технік) |

## Обмеження машин

### Дільниця нарізки (G01-G30)
- **Максимум**: 5 аплікаторів на машину
- **На машині**: 2 аплікатори (робочі)
- **На стелажі**: 3 аплікатора (запас)

### Дільниця кримпування (P01-P05)
- **Максимум**: 3 аплікатора на машину
- **На машині**: 1 аплікатор (робочий)
- **На стелажі**: 2 аплікатора (запас)

## База даних

### Таблиці

1. **users** - Користувачі системи
2. **applicators** - Аплікатори
3. **locations** - Локації/дільниці
4. **machines** - Машини для нарізки та кримпування
5. **movement_history** - Історія переміщень
6. **blocking_history** - Історія блокування

## Функціональність

### Переміщення аплікаторів
1. Система автоматично перевіряє обмеження машин
2. Перевіряє статус аплікатора (не заблокований, не неактивний)
3. Записує переміщення в історію
4. Оновлює статус аплікатора

### Історія (мінімум 1 місяць)
- Кожне переміщення записується з часом, користувачем і коментарем
- Історія блокування ведеться окремо
- Можна фільтрувати за датою, користувачем, аплікатором

### Сповіщення
- Якщо аплікатор вже на машині: "Аплікатор вже знаходиться на машині GXX"
- Якщо машина повна: "На машині вже знаходиться максимальна кількість..."
- Якщо заблокований: "Аплікатор заблокований та недоступний..."
